# Archivos de los talleres

1. Copia el PDF u otro documento a esta carpeta (también se admiten subcarpetas).
2. Añádelo al repositorio y publica la web con esos cambios.
3. En Admin → Gestionar recursos → Añadir archivo, indica por ejemplo:
   archivos/soluciones_shell_git_2026.pdf
4. Añade título y visibilidad y guarda. El panel comprueba que el archivo existe.
5. Usa «Abrir recurso actual» para revisarlo.

En local, basta con copiar el documento aquí y arrancar el servidor.
Las rutas son relativas: funcionan también cuando la web se publica en un subdirectorio.
Respeta mayúsculas/minúsculas. Se admiten espacios y acentos.
El panel enlaza los documentos: no sube archivos ni hace commits en Git.
Los enlaces externos anteriores se conservan.

Los archivos publicados en esta carpeta son accesibles mediante su URL directa.
Oculto / Solo formadores / Todos controla su aparición dentro de la aplicación.
No guardes documentos privados en esta carpeta pública.
